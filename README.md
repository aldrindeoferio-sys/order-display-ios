# Order Display iOS

Native iOS controller for Order Display.

## v0.1.0 foundation

- SwiftUI app shell
- Local-network server connection settings
- Wolt / Foodora / Pickup order entry
- Preparing / Ready / Collected workflow model
- Customer Display launcher
- Free/Premium entitlement architecture
- Free backgrounds: Everyday + Christmas
- Premium seasonal background locking
- StoreKit 2 non-consumable purchase manager scaffold
- AdMob/UMP integration points prepared for test IDs

> Production AdMob identifiers and the App Store Connect product must be configured before release.

Product name: **Order Display**  
Premium product ID: `com.deoferioapps.orderdisplay.premium`
